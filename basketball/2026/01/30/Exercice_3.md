# Tir en situation de post-transition

**Durée :** 12 minutes  
**Effectif :** 14 personnes  
**Matériel :** Chasubles (1 couleur) 
**Terrain :** 2 demi-terrains

## Objectifs

**Prioritaires :**
- Améliorer efficacité en situation de surnombre (3v2)
- Développer prise de décision rapide en transition
- Consolider finitions après course (lay-up + tirs ouverts)

**Secondaires :**
- Renforcer retour défensif en sprint
- Créer automatismes meneur + ailiers (occupation couloirs)

## Organisation

### Composition des groupes

- **2 terrains latéraux simultanés**
- **7 personnes par terrain**
- Répartition : 3 attaquants + 2 défenseurs + 2 en attente

### Dispositif de départ

```
MILIEU DE TERRAIN

    ●           ●           ●
  (ailier)   (meneur)   (ailier)
              avec 🏀


         ●           ●
      (défenseur) (défenseur)
      (retour sprint)


            PANIER
               ║
```

## Les 4 rôles de l'exercice

### 1. Meneur·euse
- Départ avec ballon au milieu de terrain
- Mène la contre-attaque
- Décide : passer ou tirer
- **Après action** : va en file défenseur

### 2. Ailiers·ères (×2)
- Courent les couloirs gauche et droite
- Se rendent disponibles pour passe
- Tirent si ballon reçu et ouvert
- **Après action** : vont en file attente

### 3. Défenseurs·euses (×2)
- Partent en retour défensif (sprint arrière ou latéral)
- Tentent de gêner/empêcher le tir
- Si récupération → relancent dans l'autre sens (2v1)
- **Après action** : restent en attaque pour le 2v1, puis file attente

### 4. File d'attente (×2)
- Observent, se préparent
- Entrent comme nouveaux défenseurs à la prochaine rotation

## Déroulement

### Phase 1 : Attaque 3v2 (durée : ~10 secondes)

1. **Départ**
   - Meneur part en dribble rapide depuis milieu terrain
   - Ailiers sprintent dans les couloirs (largeur maximale)
   - Défenseurs sprintent en retour défensif

2. **Contrainte temps**
   - **Maximum 5 secondes** pour tirer (après avoir franchi milieu terrain)
   - Coach compte à voix haute : "5...4...3...2...1...TIR!"

3. **Prise de décision meneur**
   - Si couloir libre → passe à ailier
   - Si défense mal placée → lay-up direct
   - Si espace → tir personnel

4. **Issue**
   - **Tir réussi** → 1 point attaque
   - **Tir raté** → phase 2
   - **Pas de tir en 5 sec** → 0 point, rotation

### Phase 2 : Contre-attaque 2v1 (durée : ~8 secondes)

**Déclenchée si les défenseurs récupèrent le rebond**

1. **Les 2 défenseurs** deviennent attaquants
2. **1 seul attaquant** (souvent le meneur) revient défendre
3. **Sens inverse** : attaque vers l'autre panier
4. **Contrainte** : Tirer dans les 5 secondes

5. **Issue**
   - **Tir réussi** → 1 point défense
   - **Sinon** → fin de séquence

### Rotation (après chaque séquence complète)

```
Meneur → Défenseur 1
Ailier 1 → Défenseur 2
Ailier 2 → File attente
Défenseur 1 → File attente (après 2v1)
Défenseur 2 → File attente (après 2v1)
File attente 1 → Meneur
File attente 2 → Ailier 1
File attente 3 → Ailier 3
```

### Timing

- **1 séquence complète** : ~25-30 secondes
- **Environ 16-20 séquences** en 12 minutes
- Chaque joueur : 5-6 passages

## Consignes par niveau

### Avancé

**En attaque (3v2) :**
- Prise de décision instantanée (< 2 secondes)
- Lecture défensive : où est le trou ?
- Tir en mouvement si ouvert
- Passes précises et rapides

**En défense (retour) :**
- Sprint maximal
- Protéger d'abord le panier (lay-up)
- Communication : "J'AI LE MENEUR !" / "COUVRE L'AILE !"

**Objectif réussite :** 70% des attaques 3v2

### Débutant

**En attaque (3v2) :**
- Privilégier le **lay-up** (plus sûr que tir extérieur)
- Ralentir légèrement si nécessaire pour contrôler
- Passer si pas d'option claire

**En défense (retour) :**
- Sprint sans se retourner complètement (backwards ou latéral)
- Se placer entre ballon et panier
- Lever les bras pour gêner

**Objectif réussite :** 40-50% des attaques 3v2

### Retour de blessure

**Rôle prioritaire :** Ailier
- Course modérée (70-80% vitesse max)
- Se rendre disponible pour passes
- Tir si reçoit ballon, sinon passe

**Rôle évité :** Meneur
- Trop de sprints avec changements direction

**Limitation :** Peut passer son tour en défense (2v1) si fatigue

## Règles spécifiques

### Temps de jeu
- **5 secondes maximum** après milieu terrain (3v2)
- **5 secondes maximum** pour contre (2v1)
- Coach chronomètre à voix haute

### Contraintes techniques
- **Dribbles limités** : Maximum 3-4 dribbles pour le meneur
- **Passes autorisées** : Illimitées
- **Zone de départ** : Strictement milieu terrain (pas de triche)

### Scoring

| Situation | Points |
|-----------|--------|
| Panier 3v2 réussi | 1 point attaque |
| Panier 2v1 réussi (défense) | 1 point défense |
| Pas de tir en temps imparti | 0 point |
